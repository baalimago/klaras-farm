# Klara's Farm

A playful, language-independent app that helps toddlers learn words together with a parent. iPad-first, runs in any browser. Python backend on Wasmer Edge, vanilla JS frontend.

- Design notes, decisions and architecture/testing requirements: [design/DESIGN.md](design/DESIGN.md)
- Look-and-feel sketches (open in a browser): [design/sketches/farm-sketches.html](design/sketches/farm-sketches.html)
